# Convention Schedule

A WordPress plugin for managing and displaying a convention or event workshop schedule. It handles dates, times, rooms and categories, and offers table, card and grid layouts.

- **Schedules**: one for each convention or workshop schedule.
- **Workshops**: the individual sessions.
- **Categories**: classify workshops and color their bars.

Show a schedule with `[convention_schedule schedule="your-schedule-slug"]`. The full attribute list is in the admin under **Workshops → Setup & Shortcodes**.

## Install

To install a release, download its plugin zip, then go to **Plugins → Add New → Upload Plugin** in WordPress. If an older version is installed, choose **Replace current with uploaded**.

See [CHANGELOG.md](CHANGELOG.md) for version history.
